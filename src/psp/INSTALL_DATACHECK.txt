OptiCraft for PSP - Data check / texture viewer
===============================================

You need: a PSP with custom firmware (ARK-4, PRO or similar) and a Memory Stick.

1. Plug the Memory Stick into your computer (or put the PSP in USB mode:
   Settings > USB Connection).
2. Open the Memory Stick. Look for a folder called PSP at its root.
3. Copy the PSP folder from this download onto the Memory Stick root. If asked
   about merging folders, say yes. Result:
       PSP/GAME/OptiCraft/EBOOT.PBP
       PSP/GAME/OptiCraft/assets.pak
   (A PSP Go uses the same layout on its internal storage.)
4. Eject safely, then on the PSP go to Game > Memory Stick (or Internal Storage).
   "OptiCraft Data Check" will be in the list. Press X to start it.

What you will see
-----------------
First a text report (storage, texture decoding speed). Press X to open the viewer.

The viewer shows the SAME texture twice, on purpose, to find the gray-squares bug:
  LEFT  = drawn by the CPU straight into video memory (always works if decoding is OK)
  RIGHT = drawn by the PSP graphics chip (the way the real game will draw)
  A small colour gradient square in the middle proves the graphics chip works at all.
Tell me which side shows the picture, which shows gray, and whether the gradient shows.

Viewer controls (this is the real game layout, so this also tests it):
  Analog nub ........ pan the image
  Triangle / Cross .. zoom in / out
  D-pad left/right .. previous / next texture
  D-pad up .......... reset view
  Select ............ toggle sharp / smooth filtering
  Start ............. HOLD for 1.5 seconds to quit (a quick tap does nothing)
The bottom row "Tested:" lights up green for each action you have tried.

If the game crashes, a red crash report appears (with an address and the last
stage reached) and waits for a button press. Take a photo of it.

It writes datacheck.log beside the EBOOT (every stage reached, every button
change, texture pixel values). Please send me that file.
